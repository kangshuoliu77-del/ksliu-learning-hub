赵世钰老师《强化学习的数学原理》课程及教材资料。

- [教材官方 GitHub 仓库](https://github.com/MathFoundationRL/Book-Mathematical-Foundation-of-Reinforcement-Learning)

## 简介

这本书从数学角度系统介绍强化学习的基本原理，包括：

- Bellman equation
- Monte Carlo methods
- Stochastic approximation
- Temporal-Difference learning
- SARSA
- Q-learning
- Value function approximation
- Policy gradient
- Actor-Critic
